# CodeAlpha Image Gallery

## 📌 About the Project

This Image Gallery is a responsive and interactive web project developed as part of my **CodeAlpha** Frontend Development Internship.

The project allows users to browse images through a clean gallery interface and view them in an interactive lightbox.

## ✨ Features

- Responsive image gallery
- Interactive lightbox preview
- Previous and Next navigation
- Keyboard navigation
- Click outside to close
- Smooth image transitions
- Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 📚 What I Learned

Through this project, I practiced:

- DOM Manipulation
- JavaScript Functions
- Event Handling
- Keyboard Events
- Responsive Web Design
- Dynamic Content
- Clean and reusable code
